# Model assumptions and ambiguity register

The six-page local IEEE paper was read completely, with visual inspection of
pages 3–5 (equations, Algorithm 1, workflow, Table II and plots). The paper is
authoritative but incomplete. This implementation is a **paper reconstruction**.
Published expressions remain available even where the event abstraction differs.
No original code/raw data, exact reproduction, independent experimental validation,
or microscopic quantum-protocol fidelity is claimed.
